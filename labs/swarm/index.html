How it works

  1. 1
    Local rules. Every agent only sees its neighbours. It keeps its distance, matches their heading and drifts toward the group, plus a pinch of chaos.
  2. 2
    Gossip. An agent that spots a task tells the agents inside its gossip radius, and they pass it on. The closest one picks the task up.
  3. 3
    Handoffs. Carriers head for the Done hub and pass the task to any neighbour that is closer to it. Every carrier counts as one hop.

aA note from Adelia

This is how I design multi-agent systems: small agents with local rules, a shared memory they all read and write, and clean handoffs whenever someone else is better placed to finish the job. The messages are drawn on purpose. If I can’t see who told whom what, I can’t debug the swarm, so observability ships on day one, not after the first incident.
